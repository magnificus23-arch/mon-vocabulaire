📋 Промпт для составления словаря с ИИ

Приложите текст и отправьте этот промпт ИИ-ассистенту — он подготовит CSV-файл, который можно импортировать в урок.

Подготовь словарь для человека, изучающего язык. Словарь нужен в виде файла в формате CSV с пятью столбцами, оформленного по образцу:
французское	часть речи	транскрипция	перевод	вес
Parler	v.	paʁ.le	Говорить	1

Корректные варианты записи частей речи: n.m., n.f., adj., adj.m., adj.f., v., v.tr., v.intr., v.pron., adv., prép., conj., interj., pron., art.déf., art.ind., adj.num. 
Каждое существительное запиши вместе с неопределенным артиклем (используй только un или une) в соответствии с его грамматическим родом, например, "une voiture". Если встречается слово с определенным или партитивным артиклем, замени его на неопределенный. Транскрипции нужны корректные именно для французского языка в соответствии с IPA. Вес каждого слова = 1 по умолчанию. В файле CSV в качестве разделителя используй запятую. Файл должен содержать заголовок с названием столбцов. Не включай в словарь такие отдельные слова, как артикли и местоимения. Если у слова есть несколько вариантов перевода на русский язык, укажи их через точку с запятой (не более трех вариантов).
📖 Как пользоваться приложением
Уроки — создавайте тематические уроки и добавляйте слова вручную или импортируйте из CSV.
Вес слова — от 0.01 до 2.0. Слова с низким весом (трудные) попадаются чаще. Порог «сложное» < 0.5, «освоенное» > 1.5.
Тренировка — нажмите «Вперед!» для тренировки по всем урокам или ▶ внутри урока. Правильный ответ повышает вес, ошибка — снижает.
Импорт CSV — формат: французское, часть речи, транскрипция, перевод, вес. Используйте промпт выше для генерации файла с помощью ИИ.
Сохранение — данные хранятся в браузере. «Сохранить» / «Загрузить» для резервной копии в JSON.

⚙️ Настройки множителей весов

Три значения для каждого случая: стрик 0, стрик 1 (или −1), стрик 2+ (или −2+).
